### 3️⃣ 使用实用工具

**添加命令别名:**
```bash
# 编辑.bashrc
vim ~/.bashrc

# 添加这些别名
alias lnmp='cd /home/monika/my-LNMP-project'
alias dps='docker ps'
alias dlogs='docker compose logs -f'

# 生效
source ~/.bashrc

# 之后可以直接使用:
lnmp           # 快速进入项目目录
dps            # 查看容器
```
