### 🛠️ 项目配置文件

#### 核心配置

1. **docker-compose.yml** - 服务编排文件
   - 定义了nginx, php, db三个核心服务
   - 配置了网络和数据卷
   - 使用环境变量实现灵活配置

2. **.env** - 环境变量配置
   - 项目名称和版本配置
   - 数据库连接信息
   - 端口映射设置
   - ⚠️ 包含密码,注意安全!

3. **Makefile** - 运维快捷命令
   - 本小姐精心优化的命令集
   - 包含40+常用运维命令
   - 彩色输出,易于使用

#### 服务配置

1. **Nginx配置**
   - `nginx/nginx.conf` - 主配置文件
   - `nginx/conf.d/default.conf` - 站点配置

2. **PHP配置**
   - `php/Dockerfile` - PHP镜像构建
   - `php/php.ini` - PHP运行时配置
   - `php/fpm-pool.d/www.conf` - FPM进程池配置

3. **MySQL/MariaDB配置**
   - `mysql/my.cnf` - 数据库配置
   - `mysql/initdb/` - 初始化SQL脚本

## 💡 实用技巧

### Tip 1: 使用别名提高效率

在 `~/.bashrc` 中添加:

```bash
# Docker快捷命令
alias dps='docker ps'
alias dpa='docker ps -a'
alias dlogs='docker compose logs -f'
alias dup='docker compose up -d'
alias ddown='docker compose down'
alias dexec='docker exec -it'

# 项目快捷目录
alias lnmp='cd /home/monika/my-LNMP-project'

# 然后执行
# source ~/.bashrc
```

---

### Tip 2: 善用Makefile

```bash
# 不要记复杂的命令,直接用make
```

## 📊 学习效果自测

### 自测题(基础)

1. 如何查看正在运行的容器?
2. 如何进入PHP容器?
3. 如何查看Nginx日志?
4. 如何重启所有服务?
5. 如何备份数据库?

<details>
<summary>点击查看答案</summary>

```bash
1. docker ps 或 make ps
2. make shell-php
3. make logs-nginx
4. make restart
5. make backup
```
</details>

---

### 自测题(进阶)

1. 容器间如何通过服务名通信?
2. 如何添加新的PHP扩展?
3. 502错误的常见原因是什么?
4. 如何限制容器的CPU和内存?
5. 什么是数据卷和绑定挂载的区别?

<details>
<summary>点击查看答案</summary>

```
1. 通过Docker网络的DNS解析,使用服务名(如db, php)
2. 修改Dockerfile添加扩展,重新构建镜像
3. PHP-FPM未运行或网络不通
4. 在docker-compose.yml中添加deploy.resources配置
5. 数据卷由Docker管理,绑定挂载直接映射宿主机目录
```
</details>
